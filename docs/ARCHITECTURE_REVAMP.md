## 二、业务主线（媒介代理一人闭环）

```
线索 → 商机 → 合同 → 排期执行 → 投放监控 → 结案复盘 → 回款
          ↑________________跟进记录/任务/笔记_______________|
```

每个阶段对应一个实体，每个实体有自己的工作台。**Dashboard 不是菜单，是视图。**

## 三、新菜单架构（9个，边界一刀切开）

### 1. AI助手 `agent` —— 对话入口，不做数据页
- **定位**：自然语言指挥台，不是功能导航页
- **内容**：居中输入框 + 模型选择器 + 4个场景胶囊
- **场景胶囊行为**：点"客户跟进"→ 跳到 crm 并自动带上"待跟进客户"筛选；点"媒介排期"→ 跳到 media
- **不做**：快捷工具按钮（财报分析/MD转PDF等空洞按钮全删）
- **联动**：发送问题→右下角AI面板，AI可调用 db 查当前业务数据回答

### 2. 今日工作台 `today` —— 每天打开APP的第一站（原"待办事项"改名）
- **定位**：**只显示"今天要动手做的事"**，按优先级排序，不展示统计数字
- **内容**：
  - 🔴 今天必须处理：今天到期的任务 + 今天/已逾期回款提醒（只读提醒，点"去登记"跳dev）
  - 🟡 该跟进了：沉默≥X天的客户（从crm算出来，一键写跟进记录）
  - 🟢 本周截止：本周到期的任务/排期节点
  - 快速录入条：+任务 / +跟进 / +回款
- **不做**：不展示客户列表、不展示商机进度条、不展示笔记
- **关键交互**：勾掉一个待办→直接改 db，不跳页；写跟进→弹小窗选客户+写内容→存 contactPoints
- **联动**：数据源是 tasks + payments + contactPoints + deals，全部只读引用

### 3. 客户与商机 `crm` —— 销售管道主战场
- **定位**：客户档案 + 商机阶段管理，所有客户相关操作都在这里完成
- **结构**：左右分栏
  - 左：客户列表（搜索/行业/等级筛选）
  - 右：选中客户详情抽屉，分4个tab：
    - 档案：公司信息、联系人、等级、健康度
    - 跟进记录：时间线，新增跟进按钮
    - 商机：该客户的所有商机，拖拽改阶段
    - 合同：该客户签过的合同链接
- **顶部**：商机看板（线索→MQL→SQL→报价→谈判→签约），拖拽卡片改阶段
- **不做**：不展示任务、不展示回款、不展示笔记
- **联动**：商机点"赢单"→ 自动跳 dev 新建合同草稿（客户名预填）；写跟进→自动在 today 工作台生成"下次跟进"提醒

### 4. 任务看板 `work` —— 个人执行清单
- **定位**：纯任务执行，不做OKR、不挂客户进度
- **结构**：四列看板（待办/进行中/待审核/完成），拖拽改状态
- **任务来源**：手动新建 / 从客户跟进一键转任务 / 从合同自动生成回款提醒任务
- **删**：顶部OKR进度条整块删掉（单人不需要）
- **不做**：不展示客户信息、不展示回款金额

### 5. 媒介排期 `media` —— 投放执行
- **定位**：把合同里的承诺落到日历上，跟踪执行
- **结构**：甘特图为主，每个排期条关联一个合同（显示客户名+项目名）
- **子tab**：
  - 排期：甘特图
  - 资源库：媒体资源/达人名单
  - 报价器：成本+毛利测算
  - 售后数据：投放后回传的数据
- **关键交互**：新建排期→必须选关联合同（下拉显示已有合同）
- **不做**：不做客户管理、不做合同管理

### 6. 合同与台账 `dev` —— 钱的事
- **定位**：合同签订 + 回款计划 + 回款登记
- **结构**：三个tab
  - 合同列表（新建/查看/删除）
  - 回款台账（登记回款→写paidDate）
  - 30天到期提醒
- **联动**：新建合同→自动生成30天后回款计划；登记回款→自动在 today 工作台消除提醒
- **不做**：不展示客户列表、不做报表

### 7. 知识库 `kb` —— 文档沉淀
- **定位**：笔记 CRUD，和业务数据松耦合
- **内容**：笔记列表+编辑器+标签+双链
- **新增**：笔记类型标签（方法论/复盘AAR/客户沟通纪要/日报周报）
- **不做**：不展示任务/客户/数据

### 8. 数据报表 `data` —— 只读经营分析
- **定位**：老板每周/每月看一次的体检报告
- **内容**：KPI卡 + 趋势图 + 经营活动流水
- **下钻**：点任何数字→跳到对应列表（点"签约额400万"→跳dev合同列表）
- **不做**：不能编辑数据，不能新建

### 9. 设置 `settings` —— 系统配置（从隐藏提到一级菜单）
- AI配置（模型/Key/限额）
- 数据备份/恢复/导入导出
- 窗口模式（integrated/native）
- 关于/版本

## 四、砍掉/迁移清单

| 原位置 | 内容 | 去向 |
|---|---|---|
| 团队协同-今日待办 | 6个任务勾选 | 合并到 **今日工作台** |
| 团队协同-在途商机进度 | 5个商机进度条 | 删掉，去 **crm** 看拖拽看板 |
| 团队协同-近期到期回款 | 3笔回款提醒 | 合并到 **今日工作台**（只显示提醒） |
| 团队协同-最近跟进记录 | 5条跟进 | 删掉，去 **crm** 客户详情看 |
| 团队协同-快速录入写日报/周报 | 写日报按钮 | 移到 **知识库**（笔记类型=日报） |
| 团队协同-最近笔记 | 4条笔记 | 删掉，去 **知识库** |
| 任务看板-OKR进度条 | 3条进度 | 整块删 |
| AI助手-快捷工具4个按钮 | 财报分析/MD转PDF等 | 删，这些不是功能 |
| 待办事项右侧"营销节点"卡片 | 写死节假日 | 删 |

**"团队协同"菜单整块移除**（单人工具没有团队概念，数据全部归位到实体页）。

## 五、数据联动关系图

```
[crm客户]──1:N──→[crm商机]──赢单──→[dev合同]──1:N──→[media排期]
   │                  │                  │
   │                  │                  └──1:N──→[dev回款]──登记──→[today提醒消除]
   │                  │
   └──1:N──→[crm跟进记录]──→[today生成下次跟进提醒]
                                │
[work任务]←──手动/从跟进转/从合同自动生成──┘
[kb笔记] 独立，可双链引用任意实体
[data报表] 只读聚合以上所有表
[AI助手] 可查询以上所有表
[settings] 配置
```

**核心原则：任何数据只在一个地方创建，其他地方只读引用+跳转。**

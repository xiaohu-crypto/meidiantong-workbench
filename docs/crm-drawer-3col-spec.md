# CRM 客户详情「一体化工工作台」重构规格（P1）

> 来源：`delivery/issue-list-latest.md` 唯一 P1 问题 · 目标：移除 5 个顶层 Tab，重构为「左 25% / 中 50% / 右 25%」三栏智能工作台。
> 状态：✅ 已落地（2026-09-23 · P1 三栏工作台完整实现：5 Tab 彻底移除 + 左 25/中 50/右 25 + 多层抽屉金字塔 + 预算 100% 校验 + AI 分组管理 Dropdown/置顶/拖拽 + 左栏健康度徽章/失分原因/行内编辑开票抬头税号。typecheck 0 错、vite build 成功、75 tests 全过）。

---

## 1. 目标

将客户详情从「概览 / 跟进 / 决策链 / 媒介策略 / AI 建议」5 个独立顶层 Tab，重构为一体化工作台：左栏固定基础画像、中栏纵向平铺跟进流与核心策略、右栏常驻 AI 副驾驶；决策链 / 媒介策略点击编辑或新增时统一触发右侧连续滑出抽屉（Drawer）。

---

## 2. 布局与字段

### 2.1 左栏（25%，垂直固定不随中栏滚动）
- **客户健康度**：绿色环形进度条，文案「客户健康度：70 / 100（标签：派生）」
- **客户基本信息**：2 列紧凑无边框表单
  - 开票抬头 / 税号 / 在途商机 / 累计商机额 / 品牌 / 主要联系人+职位 / 联系电话 / 邮箱 / 沟通记录
- **合同与回款快照**：合同与回款汇总（无合同时灰色扁平底卡「暂无合同」）

### 2.2 中栏（50%，主体操作区，纵向 Scroll）
- **决策链联系人**：右上角 `[+ 新增联系人]`；已有联系人卡片（职位 / 标签：[核心决策][积极支持] / 最近互动）；空白占位虚线框 `[+ 绑定上级/协同决策人]`
- **客户专属媒介策略**：未配置时居中灰字「该客户尚未配置专属媒介策略。请填写策略…」+ 醒目按钮 `[✍️ 立即配置策略]`
- **跟进时间线与关联任务**：纵向 Timeline；关联任务 `[+ 新增]` → 暂无关联任务

### 2.3 右栏（25%，AI Copilot 常驻）
- 收折开关：右下角红色魔棒圆形浮动按钮，点击向右滑出隐藏右栏，中栏自适应拉伸
- **AI 自动摘要**（顶部）：实时读取左中两栏数据生成分析摘要
- **快捷智能指令**（中部）：`[💡 帮我规划下一次跟进话术]` / `[📝 生成邮件]` 等胶囊按钮
- **AI 互动对话框**（底部固定）：聊天历史流 + 固定输入框

## 3. 右侧抽屉连续滑出（多层嵌套）

### 3.1 层级金字塔（z-index）
| 层 | z-index | 说明 |
|---|---|---|
| 底屏主页面 | 1–99 | 含一体化工作台三栏 |
| 一级遮罩 Mask 1 | 1000 | 半透明黑 rgba(0,0,0,0.3) |
| 一级抽屉 Drawer 1 | 1001 | 宽 520px，从右向左滑出（点击媒介策略 `[✍️立即配置策略]`） |
| 二级遮罩 Mask 2 | 2000 | 仅覆盖 Drawer 1 及其左侧，低透明度 rgba(0,0,0,0.15) |
| 二级抽屉 Drawer 2 | 2001 | 宽 480px，从最右侧滑出，完全叠在 Drawer 1 上方，左侧露出 40px 边缘 |

### 3.2 栈级销毁（后进先出）
- 打开二级抽屉时，按 ESC 或点击左侧外部遮罩 → 仅关闭二级抽屉；若有输入则弹二次确认气泡
- 一级抽屉内容必须完好保留
- 二级抽屉保存成功后，一级抽屉内联系人下拉框无缝热加载刷新，允许直接勾选

### 3.3 媒介策略「预算配比」动态校验
- 输入「预计总预算」后，按选中渠道动态生成配比列表（每行 `[占比输入框(%)]` + 联动 `[预估金额(¥) 灰只读]`）+ 实时总计看板
- **提交按钮始终可点击（不置灰）**
- 校验未通过（各渠道占比之和 ≠ 100%）：抽屉不关闭；实时总计看板整行变红；输入框下方整体提示：`❌ 各媒体渠道的预算配比相加必须等于 100%（当前总计为 X%），请修正后再提交。`；光标自动聚焦首个错误输入框

## 4. AI 建议面板联动

媒介策略以 100% 成功提交回填后，右栏 AI 面板自动重载，按渠道占比固定触发 `[📊 媒介预算合理性评估]` 板块：
- 配比均衡合理：`🤖 AI 预算评估：当前预算配比极其合理。信息流主导线索获取（占比 50%）…预计能让商机转化率提升 15%。`
- 配比高风险（单一渠道 > 80%）：`🤖 AI 风险预警：检测到您将 80% 以上预算集中在单一触点，容易导致线索流流失，建议调低 20%…`

# 媒电通工作台 v0.2.1 发布说明

> 基于 v0.2.0（NocoBase 架构对齐 + 问题跟踪迁移）之上的迭代版本。

## 版本类型
次要功能版本（Feature / 重构）

## 核心变更

### 1. CRM 详情页重构为三栏工作台（GitHub Issue #1 · P1）
将原有 5-Tab 详情视图重构为 **左 25% / 中 50% / 右 25%** 三栏布局：
- **左栏**：客户基本信息（健康度环、开票抬头、在途商机、累计商机额等派生指标）+ 决策链联系人（新增入口）。
- **中栏**：360° 跟进时间线 + 客户专属媒介策略卡 + 关联任务。
- **右栏**：AI 副驾驶，实时读取左右栏上下文，提供健康/商机/最近触达摘要，快捷「规划跟进话术 / 生成邮件 / 话术库」，独立对话面板；支持 🪄 收起/展开。

### 2. 媒介策略编辑器升级为统一 Drawer + 预算配比动态校验
- 渠道预算配比采用**动态列表编辑**（渠道 + 占比），实时合计。
- **强校验**：各渠道占比之和必须等于 100%，否则红色高亮拦截、不关闭编辑框，并自动聚焦首个配比输入。
- **联动 AI**：配比合计 = 100% 后，自动在右栏触发 AI 预算合理性评估（单一触点 >80% 风险预警 / 均衡配比好评）。
- 支持总预算、预算区间、首选资源、方案附件。

### 3. 统一 Drawer 基础组件（`src/ui/common.tsx`）
- z-index 金字塔：`level 1` 遮罩 1000 / 抽屉 1001（宽 520px）；`level 2` 遮罩 2000 / 抽屉 2001（宽 480px）；滑入 ≤220ms。
- 决策人新增 Drawer 支持 `level=2`，可在策略 Drawer 之上堆叠（策略抽屉内「添加决策人」按钮触发），实现多层抽屉不串层。

### 4. 技术债清理
- 退役 5-Tab 切换与布局拖拽编辑（P4）功能，原散落的 Modal / 多抽屉系统统一收敛到 `Drawer`。

## 构建与验证

- 打包：`npm run dist`（宿主执行；本环境仅做类型校验与代码对齐）。

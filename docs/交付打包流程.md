# 媒电通工作台 - 交付与打包流程

## 日常交付流程（每次修改代码后）

```
1. 修改代码
2. npm run typecheck    # TypeScript 类型检查
3. npx vitest run       # 单元测试
4. npm run build        # 前端构建
5. npm run electron:main # 主进程构建
6. .\scripts\repack-installer.ps1  # 一键打包安装版（自动清理+验证）
7. 人工验证关键功能
8. git commit + push
```

## 打包脚本使用方法

```powershell
# 完整流程：构建 + 打包 + 清理 + 启动验证
cd D:\HaLeMa\Documents\Obsidianku\原始资料\autoclaw\app
.\scripts\repack-installer.ps1

# 跳过源码构建（已手动构建过）
.\scripts\repack-installer.ps1 -SkipBuild

# 打包后不自动启动
.\scripts\repack-installer.ps1 -NoLaunch

# 组合使用
.\scripts\repack-installer.ps1 -SkipBuild -NoLaunch
```

## 脚本自动完成的操作

| 步骤 | 操作 | 目的 |
|------|------|------|
| 1 | 停止所有应用进程 | 防止文件被占用 |
| 2 | 删除 IndexedDB LOCK | 防止数据库锁定导致加载死循环 |
| 3 | 构建源码（vite + electron:main） | 确保 dist 是最新的 |
| 4 | 从备份 asar 提取 node_modules | 保留完整运行时依赖 |
| 5 | 替换 dist / dist-electron / package.json | 注入最新代码 |
| 6 | 备份当前 asar（保留最近3个） | 可回滚 |
| 7 | 打包新 asar | 生成安装版 |
| 8 | 检查并修复 app-update.yml | 防止更新源指向错误仓库 |
| 9 | 清理临时文件（提取目录/更新缓存/Temp残留） | 防止干扰 |
| 10 | 启动应用验证 | 确认打包成功 |

## 常见问题排查

### 问题1：应用卡在"正在加载数据..."
**原因**：IndexedDB LOCK 文件残留，数据库被锁定
**解决**：
```powershell
Stop-Process -Name "媒电通工作台" -Force
Remove-Item "$env:APPDATA\meidiantong-workbench\IndexedDB\file__0.indexeddb.leveldb\LOCK" -Force
# 重新启动
```

### 问题2：弹出"发现新版本 v6.0.7"
**原因**：app-update.yml 指向了错误的仓库（mediantong-releases）
**解决**：
```powershell
# 检查
Get-Content "D:\软件安装\个人工作台\meidiantong-workbench\resources\app-update.yml"
# 确认 repo: 应为 meidiantong-workbench，不是 mediantong-releases
```

### 问题3：从 Temp 目录启动导致异常
**原因**：从压缩包直接运行，或自动更新失败残留
**解决**：
- 始终从 `D:\软件安装\个人工作台\meidiantong-workbench\媒电通工作台.exe` 启动
- 或从桌面快捷方式启动
- 清理 Temp 目录中残留的应用副本

### 问题4：asar 打包后应用崩溃
**原因**：asar 缺少 node_modules（只打包了 dist）
**解决**：必须使用 `repack-installer.ps1` 脚本，它会从备份 asar 提取完整 node_modules

## 防止同类问题的检查清单

每次交付前确认：

- [ ] `npm run typecheck` 0 错误
- [ ] `npx vitest run` 全部通过
- [ ] `npm run build` 成功
- [ ] `npm run electron:main` 成功
- [ ] 使用 `repack-installer.ps1` 打包（不是手动 asar pack）
- [ ] 打包后应用能正常启动，窗口标题为"媒电通工作台"
- [ ] 数据正常加载（不卡在"正在加载"）
- [ ] 无错误的更新提示（v6.0.7 是媒电通的版本，不是工作台的）
- [ ] 临时文件已清理
- [ ] git commit + push

## 注意事项

1. **不要手动 asar pack dist** —— 会缺少 node_modules 导致崩溃
2. **不要从 Temp/压缩包直接运行** —— 会导致路径异常和更新问题
3. **备份 asar 不要删除** —— `app.asar.bak-20260914-160204` 是 node_modules 的唯一来源
4. **IndexedDB 数据不要删** —— 只删 LOCK 文件，不要删整个 IndexedDB 目录
5. **app-update.yml 要定期检查** —— 确保 repo 指向 `meidiantong-workbench`

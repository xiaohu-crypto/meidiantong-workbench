## 二、Top5 深度调研报告

### Top 1 ｜ Twenty —— 现代 CRM 设计标杆

| 维度 | 内容 |
|------|------|
| **GitHub** | https://github.com/twentyhq/twenty |
| **文章 Star 数** | 24.4k（2025-01） |
| **2026 最新 Star 数** | **~45k**（两年内近翻倍，增长极快） |
| **活跃度** | 极高；YC 背书（$5M 种子轮），v2.8.0（2026-05）持续发版，公开 Roadmap+Figma 设计文件开源 |
| **开源协议** | AGPL-3.0（可自托管永久免费） |

**产品定位与目标用户**
面向中小企业的开源 CRM，定位「Salesforce/HubSpot 的现代替代品」。设计哲学是「简洁、轻量、高效」——团队因不满传统 CRM 过于复杂而立项。目标用户：快速发展的初创企业、需要基础客户管理的小型团队、开发者友好型公司。

**核心功能（≥5）**
1. **自定义对象/字段/视图**：UI 即可扩展数据模型，自定义对象+任意字段类型+对象间关系，业务结构随需演进。
2. **多视图切换**：Table / Kanban / Grouped / Sorted 视图一键切换，同一数据不同呈现。
3. **API-first 元数据驱动 GraphQL**：每个对象（联系人/公司/商机/自定义对象）都通过 GraphQL API 可查询，前后端元数据驱动。
4. **工作流自动化**：可视化工作流构建器——表单触发器、条件分支、HTTP 请求、Webhook、Serverless 函数。
5. **邮件与日历同步**：Gmail/IMAP 邮件同步到联系人时间线，Google 日历会议自动挂载到记录旁。
6. **细粒度 RBAC 权限**：自定义角色，控制谁能看/编辑哪些数据，团队协作与安全并存。
7. **暗色模式 + 快捷键 + 命令面板**：面向键盘流用户的效率设计。

**UI/UX 设计亮点（交互细节）**
- **Notion × Linear 混合审美**：界面干净、快速、低 clutter，Figma 级设计质量，被评价为「仅凭美学就能与商业 CRM 竞争」。
- **命令面板（Command Palette）**：类似 Linear/Raycast 的全局 Cmd+K 快速跳转/新建/搜索，是现代工作台的标志性交互。
- **数据视图即换肤**：同一商机列表可在表格/看板/分组间无缝切换，不丢筛选条件，降低认知负担。
- **记录侧栏时间线**：邮件、会议、笔记、任务统一聚合在联系人/公司记录右侧时间线，沟通历史紧贴数据。

**技术栈**
- 前端：React + Jotai（轻量状态管理）
- 后端：NestJS + TypeORM
- 数据：PostgreSQL + Redis + BullMQ（队列）
- 工程：Nx Monorepo，TypeScript 78%
- 扩展：`npx create-twenty-app` 脚手架 + TypeScript App 扩展机制

**可借鉴的设计模式（应用到媒电通工作台）**
1. **多视图切换（Table/Kanban/分组）** → 媒电通「客户列表」应支持表格视图（快速筛选批量操作）+ 看板视图（按跟进阶段拖拽流转）+ 日历视图（按拜访时间排布），同一数据源三种视角，切换不丢筛选。
2. **命令面板 Cmd+K 全局搜索/新建** → 媒电通工作台顶部或全局快捷键唤起命令面板，支持「新建客户/新建商机/搜索客户/跳转页面」，这是 Electron 桌面应用效率工具的核心交互。
3. **记录侧栏时间线聚合** → 媒电通客户详情页右侧时间线聚合「通话记录/拜访记录/报价单/合同/回款」，一屏看完客户全生命周期，替代多 Tab 跳转。

### Top 2 ｜ NocoBase —— 数据模型驱动的无代码工作台平台

| 维度 | 内容 |
|------|------|
| **GitHub** | https://github.com/nocobase/nocobase |
| **文章 Star 数** | 13.2k（2025-01） |
| **2026 最新 Star 数** | **~21-23k** |
| **活跃度** | 高；v2.0 已发布，100+ 官方插件，中文社区活跃，文档完善 |
| **开源协议** | 核心+基础插件完全开源，TypeScript 编写 |

**产品定位与目标用户**
极易扩展的开源 AI 无代码/低代码平台。核心理念「数据模型驱动应用」——通过配置数据表、字段、关系快速生成业务页面。目标用户：需要快速定制 CRM、资源有限的中小企业及团队；需要高度自定义、处理复杂业务流程的企业。

**核心功能（≥5）**
1. **微内核插件化架构**：一切皆插件，核心保持精简，功能通过插件扩展；官方插件+自定义插件可混用。
2. **数据模型驱动**：在 UI 定义数据表/字段/关系，自动生成 CRUD 页面与 API，业务结构与 UI 解耦。
3. **工作流引擎**：基于条件触发的自动化规则（自动通知、状态变更触发、HTTP 调用）。
4. **多数据源统一管理**：支持 MySQL/PostgreSQL/SQLite/MariaDB/MongoDB/REST API/GraphQL/JSON/Excel，跨数据源关联查询+权限控制。
5. **ACL 访问控制**：细粒度角色与权限，字段级/记录级数据范围控制。
6. **仪表盘**：饼图/折线图/柱状图/Markdown 区块拖拽拼装，一眼看全局。
7. **AI 员工集成**：将 AI 能力嵌入业务系统和流程，数据与 AI 交互在自有环境运行。

**UI/UX 设计亮点（交互细节）**
- **Schema 驱动 UI 渲染**：前端按 JSON Schema 动态渲染表格/表单/详情，改 Schema 即改界面，无需写组件——这是低代码平台的核心交互。
- **所见即所得拖拽**：仪表盘与页面布局可视化拖拽拼装，非技术人员可自助配置。
- **插件市场**：内置插件一键安装启用，功能按需加载，避免功能冗余感。
- **配置即文档**：数据模型、字段、关系在管理后台可视化呈现，新人看后台即懂业务结构。

**技术栈**
- 前端：React + Umi + Ant Design 5.0
- 后端：Node.js ≥18 + Koa + Sequelize（ORM）
- 数据：PostgreSQL（也支持 MySQL/MariaDB/MongoDB）
- 工程：Lerna + Yarn Workspaces（Monorepo）
- 模块：Server Application / PluginManager / Client UI / Database ORM / Resourcer REST / ACL / Flow Engine / AI Manager / CLI

**可借鉴的设计模式（应用到媒电通工作台）**
1. **微内核插件化架构** → 媒电通工作台可按「客户模块/商机模块/合同模块/回款模块/报表模块」拆成独立插件包，核心壳只做导航+布局+权限，业务模块按需加载。Electron 主进程作为壳，Renderer 按插件懒加载，控制首包体积。
2. **数据模型驱动 + Schema 渲染** → 媒电通客户/商机/合同的字段定义抽成配置层（JSON Schema），表格列、表单字段、详情页区块由 Schema 自动生成。后续加字段（如「广告位类型」「刊例价」）只需改配置不改代码，这是广告行业多客户定制的刚需。
3. **工作流引擎（条件触发自动化）** → 媒电通配置自动化规则，如「商机阶段推进到→合同签订」自动建合同任务、「回款到期前 3 天」自动提醒销售。把销售重复操作沉淀为可配置规则。

### Top 3 ｜ Huly —— 项目管理+CRM+Chat 一体化工作台

| 维度 | 内容 |
|------|------|
| **GitHub** | https://github.com/hcengineering/platform |
| **文章 Star 数** | 18.1k（2025-01） |
| **2026 最新 Star 数** | **~24k** |
| **活跃度** | 高；Huly/TraceX 等产品团队基于此 Platform 构建产品，生态活跃 |
| **开源协议** | 宽容开源协议（EPL/Apache 类） |

**产品定位与目标用户**
开源 all-in-one 平台，定位「Linear + Jira + Slack + Notion 的自托管替代品」。一个平台覆盖：项目管理、CRM、实时聊天、HRM、ATS。目标用户：需要工具整合、减少 SaaS 堆叠的中型团队与产品研发团队。

**核心功能（≥5）**
1. **项目管理全套**：Issues / Milestones / Sprints / Roadmap，类 Linear 工作流。
2. **CRM 模块**：客户/商机/销售流程管理，与项目打通。
3. **实时 Chat（类 Slack）**：团队消息、频道、讨论，与客户/项目记录联动。
4. **Notion 式协作文档**：富文本文档，与项目/客户关联。
5. **双向 GitHub 同步**：Huly Issue ↔ GitHub Issue/Project 双向同步，可作为 GitHub Issues 的高级前端。
6. **AI 实时转录**：会议/沟通内容实时文字转录并自动整理讨论要点。
7. **内置视频会议**：无需离开工作区即可邀请外部访客开会。
8. **Team Planner**：团队日程大盘，宏观视角跟踪所有人的任务排布。

**UI/UX 设计亮点（交互细节）**
- **键盘优先**：全量键盘快捷键即时访问常用操作，重度用户效率极高——桌面应用应重点借鉴。
- **多合一界面无切换**：Chat/项目/文档/CRM 在同一侧边栏导航下无缝切换，无需在多个 SaaS 间跳来跳去。
- **虚拟办公室空间**：可按部门/事件创建定制化协作空间，场景化工作台组织。
- **Bidirectional Sync 双向同步**：与 GitHub 等外部系统双向打通，数据源单一不割裂。

**技术栈**
- 全栈 TypeScript Monorepo
- 包管理：Rush（微软系 Monorepo 工具）
- 部署：Docker Compose 编排
- 架构：模块化微服务，Platform 之上可构建 Huly/TraceX 等不同产品

**可借鉴的设计模式（应用到媒电通工作台）**
1. **All-in-One 侧边栏整合** → 媒电通工作台左侧导航按「工作台首页/客户/商机/合同/回款/日程/消息」组织，所有模块在一个 Electron 窗口内切换，避免销售同时开 CRM+微信+Excel 三个应用。这是桌面应用的天然优势。
2. **键盘快捷键+Team Planner 大盘** → 媒电通工作台内置「团队销售大盘」日历视图：看板主管一屏看到所有销售的今日拜访安排、商机跟进节点。配合快捷键快速建客户/改阶段，提升主管管理效率。
3. **记录内嵌沟通（Chat 与客户记录绑定）** → 媒电通客户详情页内嵌该客户的沟通记录（电话/微信/拜访），沟通不进独立 IM 而是挂在客户档案下，避免「聊了天找不到记录」。

### Top 4 ｜ WuKong CRM（悟空 CRM）—— 国产中文 CRM 标杆

| 维度 | 内容 |
|------|------|
| **GitHub** | https://github.com/WuKongOpenSource/WukongCRM-11.0-JAVA |
| **文章 Star 数** | 6.4k（2025-01） |
| **Gitee 生态** | Gitee 7.6k Star / 4.3k Fork，国内活跃度高于 GitHub |
| **活跃度** | 中高；已迭代至悟空 CRM 15（AI CRM），Java 11.0 版为 Spring Cloud Alibaba 微服务架构 |
| **技术分支** | Java 版（Spring Cloud Alibaba）+ PHP 版（TP5）双后端，Vue 前端 |

**产品定位与目标用户**
中国市场的开源 CRM，专为中小企业设计，覆盖从线索获取到回款的全业务流程。目标用户：需要快速实施 CRM、与本地化平台集成的国内中小企业；媒体广告销售团队是典型场景。

**核心功能（≥5）**
1. **客户全生命周期管理**：客户信息管理、自定义字段与标签、联系人管理、精准营销分层。
2. **销售管理自动化**：线索管理、商机/机会管理、销售管道、销售预测。
3. **合同与回款管理**：合同管理、回款跟踪，与销售流程闭环。
4. **售后服务与工单**：工单管理、客户反馈处理、售后支持。
5. **市场活动管理**：市场活动策划执行、效果跟踪。
6. **细粒度角色权限**：不同角色看到不同数据范围，保护敏感客户数据。
7. **移动端适配**：销售外出拜访可通过移动端操作。
8. **本地化集成**：支持微信/微博等社交媒体平台集成，适配中国市场。

**UI/UX 设计亮点（交互细节）**
- **中文化业务语言**：术语贴合国内销售习惯（线索/商机/回款/公海池），无翻译腔。
- **数据范围权限**：销售只能看自己客户、主管看团队、老板看全公司——这是国内团队 CRM 刚需。
- **移动端优先适配**：外出拜访场景下的客户查看/签到/记录。

**技术栈**
- 后端：Spring Cloud Alibaba 微服务架构（Java）
- 前端：Vue 2.5 + Vue Router + Vuex + Element UI 2.12 + Axios
- 形态：前后端分离
- 多语言：中文为主，本地化适配

**可借鉴的设计模式（应用到媒电通工作台）**
1. **国内销售业务术语体系** → 媒电通直接复用悟空的中文 CRM 术语：线索/客户/联系人/商机/销售阶段/合同/回款/公海池/跟单记录。媒体广告行业再加「刊例/排期/广告位」即可，无需自创概念。
2. **数据范围权限（本人/本组/全公司）** → 媒电通工作台按角色控制数据可见范围：销售只看自己客户、销售主管看本组、老板看全公司。媒体广告行业客户资源敏感，这是必做项。
3. **移动端轻量拜访记录** → 媒电通配套移动端/H5：销售外出拜访客户时快速签到、记录拜访要点、拍照存证，数据回流桌面端。

**产品定位与目标用户**
开源 ERP+CRM，主打 Quote-to-Cash（报价到回款）一体化。目标用户：希望通过单一工具整合客户与财务的中小企业，尤其适合需要「报价→发票→支付→客户」闭环的团队。

**核心功能（≥5）**
1. **报价管理（Quote）**：快速创建报价单，可一键转为发票。
2. **发票管理（Invoice）**：发票生成、状态跟踪。
3. **支付管理（Payment）**：支付记录与跟踪，回款可视化。
4. **客户管理**：客户档案集中管理。
5. **库存/会计/HR 模块**：除 CRM 外整合库存、会计、人力资源。
6. **多公司/多分支机构**：支持多公司/多分支数据隔离。
7. **多语言/多货币**：国际化运营友好。

**UI/UX 设计亮点（交互细节）**
- **SaaS 式干净界面**：Ant Design 组件体系，开箱即用无需 onboarding，视觉现代。
- **Quote-to-Cash 流程化**：报价单一键转发票、发票关联支付，业务流在界面上线性串联，操作路径短。
- **Redux + Context 状态管理**：前端数据层清晰，列表/详情/表单状态流转可预测。

**技术栈**
- 前端：React + Ant Design + Redux + React Context（Hooks）
- 后端：Node.js + Express.js
- 数据库：MongoDB
- 架构：MERN Stack，模块化

**可借鉴的设计模式（应用到媒电通工作台）**
1. **Quote-to-Cash 线性流程串联** → 媒电通「报价单→合同→回款」在界面上做成线性流水线：商机赢单后一键生成报价单，报价确认转合同，合同关联回款计划。媒体广告的「刊例报价→排期合同→广告款回款」完全套用此模式。
2. **多公司/多分支机构数据隔离** → 媒电通若服务多家广告代理或有分公司，应支持多组织数据隔离与切换，一套底座服务多个业务实体。
3. **Ant Design 组件体系快速落地** → 媒电通桌面端若选 Ant Design Vue/React 组件库，可直接复用表格/表单/弹窗/卡片模式，快速搭建专业 B 端界面，降低设计成本。

## 五、调研结论摘要

1. **设计标杆首选 Twenty**：现代 CRM 的 UI/交互天花板，命令面板、多视图、记录时间线是媒电通工作台最该直接抄的三件套。
2. **架构标杆首选 NocoBase**：微内核插件化 + 数据模型驱动，为媒电通 Electron 工作台提供「壳+模块」的可扩展架构蓝图，应对广告行业多客户定制。
3. **形态标杆首选 Huly**：All-in-One 侧边栏整合，证明「一个窗口装下 CRM+项目+沟通」是可行的工作台形态，桌面应用天然具备此优势。
4. **业务标杆首选 WuKong**：中文 CRM 术语、数据范围权限、微信集成，是国内媒体广告业务场景最贴近的参考。
5. **流程标杆首选 iDURAR**：Quote-to-Cash 线性串联，直接映射媒体广告「报价→合同→回款」业务闭环。

> **一句话行动建议**：媒电通工作台首期聚焦 P0 五项（多视图 + 时间线 + 数据权限 + 中文术语 + Quote-to-Cash 流程），即可达到「现代 UI + 国内业务可用」的及格线；P1 命令面板与插件化架构决定产品中期天花板。

## 一、P0 修复：窗口控制按钮与顶栏融合

### 问题

窗口控制按钮（最小化 / 最大化 / 关闭）显示在独立白色条上，与应用顶部导航栏视觉分离，浅色 / 深色主题下均有割裂感。

### 根因



1. **高度不匹配**：`titleBarOverlay height: 38` ≠ `.topbar height: 52px`，窗口控制按钮在 38px 系统条上，与 52px 应用顶栏分离

2. **深色主题颜色不匹配**：overlay color `#0E0F13`（=--bg）≠ topbar `--surface: #16181D`，深色下两条颜色不同加剧分离感

### 修复（electron/main.ts）



| 位置                 | 修改前                            | 修改后                            |
| ------------------ | ------------------------------ | ------------------------------ |
| 初始创建（line 38）      | `color: "#0E0F13", height: 38` | `color: "#16181D", height: 52` |
| 主题切换（line 119-121） | 深色 `#0E0F13`, height 38        | 深色 `#16181D`, height 52        |

### 验证



* CDP 截图：深色主题顶栏与窗口顶部完全融合，无分离白条

* CDP 截图：浅色主题顶栏（#FFFFFF）与 overlay 一致

* 窗口控制按钮区域（系统绘制，CDP 截图不显示）现在与 52px 顶栏等高对齐

## 三、竞品功能复刻（4 项）

### 功能 1：客户列表多视图切换（表格 / 看板）

**设计来源**：Twenty / Huly 多视图切换

**文件**：`src/pages/CRM.tsx` + `src/styles/app.css`

**实现**：



* 工具栏添加 Segmented 切换「表格 / 看板」，激活态 `var(--brand-soft)` + `var(--brand)`

* 看板按 `customerStage()` 分 4 列（潜在 / 有效 / 合作 / 流失），每列头显示阶段名 + 客户数

* 卡片内容：客户名（加粗）、行业 chip、等级 chip、健康度（颜色按阈值）、最近跟进时间

* 点击卡片复用 `setOpenId` 打开 360° 抽屉

* 视图状态持久化到 `db.setSetting("crmViewMode", ...)`

* 空列显示「暂无客户」占位

### 功能 2：筛选条件 inline chips

**设计来源**：Huly P0-2 inline filter chips

**文件**：`src/pages/CRM.tsx` + `src/styles/app.css`

**实现**：



* 工具栏下方一行，仅当 `q/industry/stageFilter/groupBy` 任一非空时渲染

* 4 种胶囊 chip：搜索 / 行业 / 阶段 / 分组，点击 × 清空对应字段

* 样式 `.filter-chip`：`var(--surface-2)` 背景、`var(--ink-3)` 文字、hover 变 `--ink-2`、× hover 变 `--danger`

* 无活跃筛选时不占空间

### 功能 3：商机赢单一键建合同（Quote-to-Cash）

**设计来源**：iDURAR Quote-to-Cash 线性流程

**文件**：`src/pages/Dev.tsx`

**实现**：



* 商机详情抽屉底部，当 `stage === "签约"` 时显示「生成合同」按钮（与「编辑商机」并排）

* Modal 预填：合同名 = 商机 title、金额 = 商机 value、签订日期 = 今天

* 确认后写入：


  * `db.put("contracts", { id: uid("ct"), customerId, name, amount, signDate, status: "执行中" })`

  * `db.put("payments", { id: uid("pay"), contractId, customerId, amount, dueDate: signDate+30天, status: "未到" })`

* `useToast` 提示「合同已生成，回款计划已创建」，调 `props.reload()`

### 功能 4：空状态 CTA 引导

**设计来源**：Huly P0-4 空状态插画 + CTA

**文件**：`src/pages/CRM.tsx`

**实现**：



* `customers.length === 0`：IconUsers 大图标 + 「暂无客户」+ 副标题 + 「新增客户」主按钮

* `customers.length > 0 && rows.length === 0`（筛选无匹配）：🔍 + 「无匹配客户」+ 「清除筛选」ghost 按钮（一键清所有筛选）

* padding 60px 20px，次要文字 `var(--ink-3)`

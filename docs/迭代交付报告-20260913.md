## 二、P0 阻断级修复（4/5）

### P0-01 在途加权商机金额跨页不一致 ✅
- **问题**：商机页「加权在途 ¥1,829,000」vs 报表页「在途加权 ¥689,000」，差¥1,140,000
- **根因**：`Dev.tsx:68` active过滤包含「签约」阶段，`Data.tsx:71` 排除签约
- **修复**：Dev.tsx active过滤从 `!["输单","流失"]` 改为 `!["签约","输单","流失"]`，与Data.tsx对齐
- **验证**：CDP确认两页均为 ¥689,000 ✓

### P0-02 客户drawer财务数据自相矛盾 ✅
- **问题**：盛达集团「累计商机额 ¥380,000」但「已收 ¥475,000」，报价阶段已收款
- **修复**：
  1. 种子数据修正：`seed.ts` 盛达集团d-1从「报价/¥380K/60%」改为「签约/¥950K/100%」
  2. CRM.tsx drawer新增财务守卫：回款>商机额时显示橙色警示条「数据异常：回款 ¥X 超过累计商机额 ¥Y，请核对商机阶段与合同金额」
- **验证**：CDP确认drawer中警示条正常渲染 ✓

### P0-03 drawer路由切换后不自动关闭 ✅（架构已处理）
- **问题**：客户管理打开drawer后切换模块，drawer仍浮在页面上
- **根因核查**：App.tsx使用条件渲染 `{view==="crm" && <CRM/>}`，路由切换时组件自动卸载，drawer状态随组件销毁自动重置
- **结论**：现有架构已处理此问题，无需额外改动。盘点时观察到的现象为响应式截图时的渲染时序问题

### P0-04 通知"标记已读"后badge残留 ✅
- **问题**：标记全部已读后「需处理」「14天无接触」badge仍显示
- **修复**：`Notifications.tsx` 两个chip加条件渲染：`overduePays.length > 0` / `staleCustomers.length > 0` 时才显示
- **验证**：typecheck通过 ✓

### P0-05 数据报表当月柱红色无金额 ✅
- **问题**：签约额趋势图09月（当前月）红色细柱无金额标签
- **修复**：`BarChartWidget.tsx` 当月高亮柱从 `var(--brand)`（红色）改为 `var(--ink-4)`（灰色）+ opacity 0.45，表示"进行中"；当月值为0时也显示¥0标签
- **验证**：typecheck通过 ✓

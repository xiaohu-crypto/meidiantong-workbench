# 媒电通工作台 v0.2.2 · 交互规格文档（PRD）

> 版本：v1.0 · 冻结日期：2026-09-25
> 设计风格：Finexy Finance Dashboard（Stripe/Linear 级别）

### 1.2 物理规格

- 圆角：`--radius-xl: 24px`（卡片）、`--radius-lg: 16px`（按钮）、`--radius-md: 8px`（标签）
- 阴影：卡片 `0 4px 24px rgba(18,19,26,0.015), 0 12px 36px rgba(18,19,26,0.03)`
- 过渡：所有颜色 `0.22s cubic-bezier(0.4,0,0.2,1)`
- 字号阶：大数字 `text-4xl font-mono font-black`、卡片标题 `text-sm font-black`、正文 `text-xs`、辅助 `text-[10px]`
- 滚动条：5px 宽，透明轨道，圆角滑块

### 1.3 全局交互

| 操作 | 行为 |
|---|---|
| 主题切换 | 侧边栏底部按钮，light/dark 切换，localStorage 持久化 `mdt_theme` |
| 全局搜索 | 顶部搜索框，`Ctrl+K` 唤起快速记录，搜索客户/商机/笔记 |
| 通知铃铛 | 右上角，红点角标显示逾期数量，点击展开通知面板 |
| 头像菜单 | 右上角，下拉：个人设置/退出 |
| 快捷键 | `Ctrl+K` 快速记录、`Ctrl+1~9` 切换菜单 |
| 侧边栏 | 64px 图标态 ↔ 240px 展开态，可折叠 |

## 二、9 个菜单页面规格

### 2.1 首页（home）

**布局**：4 列 KPI + 2 列大卡片 + 全宽建议表格

**组件清单**：

| 组件 | 位置 | 交互 |
|---|---|---|
| 欢迎语 | 顶部 | "下午好，老板" + 今日待办数 |
| KPI×4 | 横排 | 在途商机总额（¥1,020,000，↑16笔）、本月已回款（¥860,000，↑7.2%，珊瑚橙高亮卡）、逾期应收（¥240,000，↓2笔，红色数字）、今日新线索（8，↑3） |
| 单兵WIP负载限额 | 左卡 | 进度条（当前6笔/上限5笔，红色超限20%）+ "批量跟进"主按钮 |
| 媒介成本精算 | 右卡 | 采购成本¥1,095,000 / 客户报价¥1,250,000 / 预估净利¥155,000 / 毛利率12.4% |

## 三、全局状态与弹窗规格

### 3.1 Modal 规范

- 宽度：详情 720px、编辑器 800px、确认对话框 480px
- 遮罩：`rgba(0,0,0,0.4)`，点击遮罩关闭
- 动画：淡入+上移 8px，0.2s
- 关闭：右上角 ✕ / ESC 键 / 点遮罩

### 3.2 空状态 / 加载 / 错误

| 状态 | 表现 |
|---|---|
| 加载 | 骨架屏（卡片灰色脉冲） |
| 空数据 | 插图 + "暂无数据" + "新建"按钮 |
| 错误 | 红色提示条 + "重试"按钮 |
| 网络断开 | 顶部黄色横幅"离线模式，数据已本地保存" |

### 3.3 Toast 通知

- 位置：右下角
- 类型：成功（绿）/ 警告（黄）/ 错误（红）
- 自动消失 3 秒，可手动关闭

## 四、验收标准

1. 所有按钮 hover/active/disabled 状态正确
2. 浅色/暗色主题切换无闪烁
3. 所有列表支持分页（>20条自动分页）
4. 所有删除操作有二次确认
5. 所有表单字段有校验
6. 响应式：最小 1280px 宽度正常显示
7. 快捷键全部可用
